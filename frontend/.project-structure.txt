Sports Holics Frontend - Project Structure
===========================================

frontend/
│
├── 📱 app/                          (Next.js App Router)
│   ├── layout.tsx                   → Root layout, metadata, fonts
│   ├── page.tsx                     → Home page (main entry)
│   ├── globals.css                  → Global styles & animations
│   └── favicon.ico                  → Site icon
│
├── 🧩 components/                   (React Components)
│   ├── Header.tsx                   → Navigation header (sticky)
│   ├── BreakingNews.tsx             → Animated news ticker
│   ├── HeroSection.tsx              → Hero banner with featured story
│   ├── NewsCard.tsx                 → Reusable news card (16 uses)
│   ├── NewsCarousel.tsx             → Auto-rotating carousel
│   ├── Sidebar.tsx                  → Trending, scores, newsletter
│   └── Footer.tsx                   → Site footer with links
│
├── 📊 lib/                          (Data & Constants)
│   ├── newsData.ts                  → 16 mock news articles
│   └── constants.ts                 → Colors, config, nav items
│
├── 🏷️ types/                        (TypeScript Types)
│   └── index.ts                     → All interfaces & types
│
├── 📂 public/                       (Static Assets)
│   ├── file.svg
│   ├── globe.svg
│   ├── next.svg
│   ├── vercel.svg
│   └── window.svg
│
├── 📄 Configuration Files
│   ├── package.json                 → Dependencies & scripts
│   ├── tsconfig.json                → TypeScript config
│   ├── next.config.ts               → Next.js config
│   ├── postcss.config.mjs           → PostCSS config
│   ├── eslint.config.mjs            → ESLint config
│   └── next-env.d.ts                → Next.js types
│
└── 📚 Documentation
    ├── README.md                    → Project overview & docs
    ├── SETUP.md                     → Setup & installation guide
    ├── IMPLEMENTATION_SUMMARY.md    → What was built
    ├── QUICK_REFERENCE.md           → Quick tips & commands
    └── .project-structure.txt       → This file
